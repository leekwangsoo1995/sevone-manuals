# 現在画面を説明する方法

## 目的

Playwright MCPで取得した現在画面を起点に、利用者が尋ねた要素だけを説明します。画面全体の講義や操作手順を始める必要はありません。

## 最初に観測する情報

| 観測するもの | なぜ必要か | 例 |
| --- | --- | --- |
| 画面の身元 | 同じボタン名や表名の混同を避ける | 見出し、選択中メニュー、パンくず、URL断片 |
| 現在の対象範囲 | 数値や件数の意味を限定する | Device、Object、Group、Tenant、Team、Data Source |
| 時間的な範囲 | 値が「今」か「過去」かを判断する | Timespan、開始・終了時刻、更新時刻、自動更新 |
| 表示・集計方法 | 数値やグラフの読み違いを避ける | aggregation、unit、TopN条件、並び順、フィルター |
| 状態 | 正常・異常・操作可能性を読む | Severity、Connection Status、Health、Acknowledged、Disabled |
| 質問対象の要素 | 必要な説明に絞る | 列名、カード、Widget、タブ、ボタン、通知 |

## 要素別の説明方法

| 要素の種類 | 説明すること | 断定しないこと |
| --- | --- | --- |
| 表の列・カード | 何を表す値か、どの対象・期間か、現在の値から読める事実 | 表示されていない原因、将来の推移 |
| グラフ・Widget | 対象リソース、期間、単位、集約、凡例 | 画面外の設定、根本原因 |
| フィルター・Variables | 何を絞り込むか、今選ばれている範囲 | 選択肢に存在しない対象 |
| 状態・Severity | 状態区分の意味、現在の状態 | 原因や復旧見込み |
| ボタン・メニュー | 何の画面へ進むか、閲覧か変更か | 実行後の環境固有の結果 |
| 空表示・エラー | 現在値が表示されない事実、確認すべき範囲 | 「データがない」ことの断定 |

## 回答の最小形

```md
## この画面
- 判定: <NMS / DI> — <画面名または画面群>（確度: 高 / 中 / 低）
- 役割: <一文>

## 今見えている内容
| 画面要素 | 意味 | 今回の表示から読めること |
| --- | --- | --- |
| <見えているラベル> | <要約> | <観測した値・状態・範囲> |

## 次に確認する場所
- <画面・タブ>: <分かること>

## 留意点
- <期間、フィルター、ロール、Tenant、導入済み機能など>
```

## 不明なときの扱い

- 見出し、選択中メニュー、タブ、列名のうち、足りない情報を一つだけ追加観測します。
- 画面の一部が権限、Tenant、Team、ライセンス、Plugin、導入形態により見えない場合があります。見えないこと自体を障害と断定しません。
- ローカル資料にない項目は、観測済みの名称と位置を説明し、意味は未確認であることを明示します。
- 変更、削除、通知、権限、しきい値、Data Sourceに関わる操作は、利用者の明示承認がない限り実行しません。
