# グループとメタデータ

## 何をする場所か

グループとメタデータは、監視対象を運用上の意味で整理する領域です。物理的な構成ではなく、拠点、サービス、担当、重要度など、調査・権限・ポリシー・可視化で再利用したい軸を作ります。

## 主な機能

- デバイス・グループとオブジェクト・グループで対象を束ねます。
- メタデータで対象に属性を付与し、検索・絞り込み・分類に使います。
- グループをポリシー適用の単位にします。
- DI側の対象選択や、チーム別の説明をしやすくします。

## どこから開くか

ナビゲーション・バーの **デバイス**、または **管理** の関連項目から開きます。対象の種類により、デバイス・グループ、オブジェクト・グループ、メタデータ管理を使い分けます。

## 関連・遷移先

- 対象を登録する → [デバイスとディスカバリー](devices-and-discovery.md)
- 条件をまとめて適用する → [アラートとルール](alerts-and-rules.md)
- 利用者の見える範囲を制御する → [アクセスと認証](access-and-authentication.md)
- レポートの対象を絞る → DI の Report Editor

## 将来変更する場合の影響

グループのメンバーシップや名前を変えると、適用済みポリシー、ロールによる閲覧範囲、DIのフィルターやレポートに影響し得ます。新規環境では、拠点・環境・サービスなど少数の安定した分類軸から始めます。
