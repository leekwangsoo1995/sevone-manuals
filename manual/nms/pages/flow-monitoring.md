# フロー監視

## 何をする場所か

フロー監視は、NetFlow、sFlow、IPFIXなどの通信記録を受信し、「誰が、どこと、どのアプリケーションで、どれだけ通信したか」を分析・アラートする領域です。通常のSNMPポーリングとは別のデータ経路です。

## 主な機能

- FlowFalcon 関連の設定で、受信・保持・処理の範囲を把握します。
- フロー・インターフェース・マネージャーで、どのデバイス／インターフェースのフローを処理するかを制限できます。
- フロー・ルール、ネットワーク・セグメント、アプリケーション／プロトコルの分類を利用します。
- フィルターやフロー・アラートにより、特定の通信条件を検出します。

## どこから開くか

フロー関連メニュー、FlowFalcon Reports、または **管理 > クラスター・マネージャー** の FlowFalcon 設定から開きます。表示可否はフロー機能の導入・権限に依存します。

## 関連・遷移先

- フロー送信元デバイスを確認 → [デバイスとディスカバリー](devices-and-discovery.md)
- クラスタ・レベルの処理設定 → [管理](administration.md)
- フロー条件の異常を確認 → [アラートとルール](alerts-and-rules.md)
- DIのFlow Explorer等で分析 → DI のフロー関連ガイド

## 将来変更する場合の影響

処理対象インターフェース、フロールール、分類、保持設定を変更すると、容量、表示データ、フロー・アラートに影響します。送信元ネットワーク機器側の設定も必要であり、NMS画面の変更だけでフローが届くとは限りません。
