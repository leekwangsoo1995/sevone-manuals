# ダッシュボード

## 何をする場所か

NMSに入った直後に、監視対象とアラートの概況を短時間で把握するための入口です。個別の異常を解決する画面ではなく、優先して掘り下げる対象を決める場所として使います。

## 主な機能

- 重大度、監視対象、稼働状況などの集計を俯瞰します。
- 表示されたデバイスやアラートから、詳細画面へ移動する起点になります。
- 新しい可視化や共有ダッシュボードの主な作成先はDIです。NMSの表示は収集・運用状況の確認に寄せます。

## どこから開くか

ナビゲーション・バーのダッシュボード領域から開きます。表示構成はロールや導入済み機能で異なります。

## 関連・遷移先

- 異常の内容を確認 → [アラートとルール](alerts-and-rules.md)
- 監視対象を確認 → [デバイスとディスカバリー](devices-and-discovery.md)
- レポートを作成・共有 → DI の Report Manager

## 将来変更する場合の影響

表示するビューや既存のNMSレポートを変更すると、運用者の監視導線が変わります。新しい共有可視化はDIで設計し、NMS内の個別画面を補助的な確認導線として残すと役割が明確です。
