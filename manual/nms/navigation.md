# NMS のメニュー地図

メニュー名は日本語UIの表記を基本にしています。権限や導入状態で一部の項目は表示されません。

```text
ダッシュボード → 現在の健全性を俯瞰 → デバイス／アラート／DIレポート
デバイス
  ├─ デバイス・マネージャー → デバイス詳細、ディスカバリー、オブジェクト
  ├─ デバイス・グループ → ポリシーの適用先
  └─ メタデータ → 検索、分類、DIでの絞り込み
イベント
  ├─ アラート → 発生中の異常を確認・確認応答
  ├─ ポリシー・ブラウザー → グループ単位の監視・通知ルール
  └─ しきい値ブラウザー → 個別条件の定義
管理
  ├─ アクセス構成 → ユーザー、ロール、認証
  ├─ クラスター・マネージャー → ピア、容量、全体設定
  ├─ オブジェクト構成 → オブジェクト種別・ルール
  └─ プラグイン／統合 → 収集・外部連携の拡張
フロー（導入時） → FlowFalcon 関連、受信、分類、表示、フロー・アラート
```

## 画面同定のヒント

- **デバイス名、IP、ポーリング状態**の一覧: デバイス・マネージャー。
- **Object、Indicator、Plugin**: 個別メトリックの収集状態を扱う領域。
- **Severity、Acknowledged、Assigned To**: アラートの確認・運用画面。
- **条件、スケジュール、適用グループ**: ポリシーまたはしきい値。
- **Peer、PAS、DNC、容量**: クラスター・マネージャー。全体影響が大きい管理領域。

## DI へ進む判断

共有グラフ、複数メトリック比較、定期レポートは、NMS 内の旧レポート画面より DI の Report Manager / Report Editor を優先します。NMS 側では、デバイス、オブジェクト、グループ、メタデータを整えることがDI利用の土台になります。
