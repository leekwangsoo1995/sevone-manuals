# 完全新規環境での見方

## 何をする場所か

単一の画面ではなく、初期導入時にNMSの各画面をどの順番で理解するかを示します。詳細な設定手順は扱いません。

## 主な機能

1. **基盤の確認**: クラスター・マネージャーでピア、容量、全体設定を確認。
2. **利用者の準備**: ユーザー・マネージャーとロールで、管理者と作業者の権限境界を決める。
3. **対象の収集**: デバイスを登録し、ディスカバリーでオブジェクトと収集可能メトリックを把握。
4. **整理**: グループとメタデータで、サービス、拠点、担当に沿って分類。
5. **異常検出**: ポリシー／しきい値とアラート画面を結び、通知先を定義。
6. **可視化**: DI を初期化し、NMSの収集対象を用いてレポートを作成。

## どこから開くか

各入口は [メニュー地図](navigation.md) を参照してください。DI の初回ブートストラップではNMSの接続先と資格情報が必要になるため、NMS側のアクセス管理を先に安定させます。

## 関連・遷移先

- 初期の収集状況 → [デバイスとディスカバリー](pages/devices-and-discovery.md)
- 初期の権限設計 → [アクセスと認証](pages/access-and-authentication.md)
- 収集後の可視化 → DI のマニュアル

## 将来変更する場合の影響

クラスタ、認証、命名、グループ設計は後からの変更範囲が広くなります。代表グループで収集とDI表示を確認し、命名と分類の方針を固めてから対象を広げます。
