# 公式ソース一覧

このリポジトリの要約は、原則として IBM Docs の **SevOne NPM 8.1.0** を根拠にします。本文や画像は転載せず、画面理解に必要な要点と公式リンクを保管します。

## 優先順位

1. 8.1.0 の該当 User Guide
2. 8.1.0 の Release Notes
3. User Guide にない管理・初期導入・認証の事項に限り、8.1.0 の関連ガイド

版が異なるページを補助的に読む場合は、8.1.0 の事実として扱いません。画面・メニュー・制約が一致するかを確認できない限り、本書には取り込みません。

## 参照時の注意

- IBM Docs の UI や一部のガイドリンクは、時期によってアクセス方法が変わることがあります。URL が開けない場合は、各製品の 8.1.0 ドキュメント・ポータルからガイド名でたどってください。
- DI 8.1.0 のリリースノートには、アプリ内の User Guide リンクが動作しない旨の注意があります。必要なときは上記の直接リンクを使います。
- 本書の作成日以降に Fix Pack、ブラウザ対応、既知の問題が変化する可能性があります。設定や変更の判断前には Release Notes を確認してください。
